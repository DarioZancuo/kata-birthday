# Kata Birthday Greetings
Training project based on:
https://codingdojo.org/kata/birthday-greetings/

## Tech Stack
- Java 21
- Spring Boot
- Spring Data JPA
- JDBC
- H2 Database
- Lombok
- JUnit 5
- Mockito

## Features
- Birthday simulation scheduler
- Birthday detection logic
- Leap year handling (29 February edge case)
- File-based repository
- H2/JPA repository support
- Console logging with SLF4J
- Unit tests with Mockito

## Profiles
Available Spring profiles:
- file
- jdbc
- jpa
